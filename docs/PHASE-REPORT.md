# تقرير المراحل — REEF

## المرحلة 1: التحليل والبنية ✅
- فحص البيئة: المستودع كان يحوي تطبيق Seven Cargo (لوجستيات) — لم يُمس؛ أُنشئت منصة REEF في `reef/` بشكل مستقل.
- Next.js 16 / React 19 / Prisma 7 / PostgreSQL 16 / Tailwind 4 / خط Cairo. دليل التصميم: أخضر زمردي `#1c7a47`، نعناعي فاتح، أبيض، زوايا دائرية، "النبتة نفسها هي الزر".

## المرحلة 2: الواجهات المتجاوبة ✅
- الرئيسية مطابقة للمرجع (الهيرو، صف النباتات القابلة للضغط، المزايا، مختارات اليوم، عروض الأسبوع)؛ موبايل أولًا ثم الكمبيوتر؛ RTL/LTR كامل مع مبدّل لغة.
- الفئات، صفحة الفئة، المنتج، البحث الفوري + بحث طبيعي بالعربية (تطبيع الهمزات/التاء المربوطة/الأرقام الهندية)، الفلاتر والترتيب، العروض، من نحن.

## المرحلة 3: قاعدة البيانات ولوحة الإدارة ✅
- 24 جدولًا (مستخدمون، جلسات، إمارات، مناطق، مواعيد، تصنيفات، موردون، منتجات، صور، سلال، حركات مخزون، سلة، طلبات، بنود، أحداث، كوبونات، قوائم، اشتراكات، مفضلة، إعدادات، سجل عمليات...).
- لوحة التحكم: الرئيسية، الطلبات (تغيير الحالة، الأوزان الفعلية، ملاحظات، تحصيل الدفع، طباعة)، المنتجات (صور، سلال، مخزون وحركاته، تكلفة الشراء)، التصنيفات، الموردون، العملاء (إيقاف/تفعيل)، مناطق التوصيل والرسوم، المواعيد والسعة، الكوبونات، الاشتراكات، التقارير (مبيعات/تكلفة/ربح تقديري/الأكثر مبيعًا/CSV)، المستخدمون والصلاحيات، سجل العمليات، الإعدادات (الضريبة، الدفع عند الاستلام، الحد الأدنى، وعد التوصيل).

## المرحلة 4: المنتجات والسلة والطلبات ✅
- سلة للزائر (كوكي) تندمج مع حساب العميل عند الدخول؛ كميات مُقيّدة بالخطوة والمخزون.
- إتمام الطلب: عنوان (إمارة/منطقة)، موعد متاح (سعة + إغلاق قبل الموعد)، كوبون، الدفع عند الاستلام، ملاحظات؛ الحد الأدنى للطلب.
- معاملة الطلب: ترقيم تسلسلي RF-000001، خصم مخزون آمن ضد التزامن، لقطة سعر/تكلفة، أحداث، سجل عمليات.
- إعادة الطلب بنقرة، قائمة أسبوعية قابلة للحفظ/التعديل، اشتراكات أسبوعية/نصف شهرية تولّد طلبات تلقائيًا.

## المرحلة 5: القوائم الذكية والاشتراكات ✅ (المساعد الذكي أُلغي بطلب المالك)
- بقي البحث الطبيعي كاحتياطي للبحث العادي فقط.

## المرحلة 6: الاختبارات والأمان ✅
- 16 اختبار وحدة (تسعير/ضريبة/كوبون/رسوم، مواعيد وتوقيت الإمارات، قصّ الكميات، البحث، أرقام الهواتف) + رحلتا API شاملتان (عميل وإدارة) تم تشغيلهما بنجاح.
- أمان: جلسات عشوائية مخزّنة كـ hash، كوكي HttpOnly/SameSite/Secure، bcrypt لكلمات مرور الموظفين، RBAC على كل مسار إداري، تحديد معدل لتسجيل الدخول وإنشاء الطلبات، تحقق Zod لكل مدخل، CSP ورؤوس أمان، فحص الصور بالبايتات السحرية، منع path traversal، عدم كشف تكلفة الشراء للعملاء.
- ملاحظة مقبولة بقرار المالك: دخول العميل برقم الموبايل بلا تحقق.

## المرحلة 7: النشر والتسليم ✅
- `docs/DEPLOYMENT.md`، `.env.example`، `npm run verify`، `npm run e2e`، بناء إنتاجي ناجح.

## غير مكتمل / يحتاج قرارًا
- الصور الحالية للمنتجات مقتطعة من الصورة المرجعية كعيّنة؛ تحتاج صورًا حقيقية من لوحة التحكم.
- إشعارات SMS/واتساب للعملاء غير مربوطة (تحتاج مزوّدًا ومفاتيح).
- الدفع الإلكتروني غير مطلوب حاليًا (الدفع عند الاستلام فقط).
