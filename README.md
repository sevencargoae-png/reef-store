# REEF | ريف — منصة توصيل الخضروات والفواكه الطازجة (الإمارات)

متجر إلكتروني ثنائي اللغة (عربي RTL / إنجليزي LTR) مع لوحة تحكم إدارية، مبني بـ Next.js 16 + React 19 + Prisma 7 + PostgreSQL + Tailwind 4.

## التشغيل محليًا

```bash
cd reef
cp .env.example .env            # عدّل DATABASE_URL و SEED_ADMIN_*
npm install                     # يولّد Prisma Client تلقائيًا
npm run db:migrate              # ينشئ الجداول
npm run db:seed                 # بيانات مرجعية (الإمارات، المواعيد) + كتالوج نموذجي + حساب مدير
npm run dev                     # http://localhost:3100
```

- المتجر: `/` · لوحة التحكم: `/admin` (دخول الموظفين برقم الهاتف وكلمة المرور).
- دخول العملاء: رقم الموبايل فقط (`/login`) — بدون كلمة مرور أو رمز تحقق (تجربة مبسّطة بطلب المالك؛ يمكن إضافة تحقق لاحقًا).
- حساب المدير الأول يُنشأ من `SEED_ADMIN_PHONE` / `SEED_ADMIN_PASSWORD`. إن لم تُضبط كلمة المرور تُولَّد عشوائيًا وتُطبع مرة واحدة في سجل الـ seed مع إلزام تغييرها عند أول دخول.

## الاختبارات

```bash
npm run verify     # lint + typecheck + اختبارات الوحدة (التسعير، الضريبة، الكوبونات، المواعيد، السلة، البحث، الأرقام)
npm run e2e        # رحلة العميل + رحلة الإدارة عبر الـ API على خادم يعمل (يحتاج ADMIN_PASSWORD)
```

## البنية

| المسار | الوصف |
|---|---|
| `src/app/(store)` | واجهة العملاء: الرئيسية، الفئات، المنتج، البحث، السلة، إتمام الطلب، الحساب (الطلبات/العناوين/القوائم/الاشتراكات/المفضلة) |
| `src/app/admin` | لوحة التحكم المحمية بالصلاحيات |
| `src/app/api` | REST API (`/api/*` للعملاء، `/api/admin/*` للموظفين، `/api/internal/*` للمهام المجدولة) |
| `src/lib/services` | منطق الأعمال: الكتالوج، السلة، الطلبات (المخزون/المواعيد/الكوبونات)، التوصيل، القوائم، الاشتراكات |
| `src/lib/pricing.ts` | حسابات الأسعار بالفلس (خصم، رسوم توصيل، ضريبة شاملة/غير شاملة) |
| `src/lib/rbac.ts` | الأدوار والصلاحيات (SUPER_ADMIN, MANAGER, OPERATIONS, SUPPORT) |
| `prisma/` | المخطط والهجرات والـ seed |

## قواعد تشغيلية مهمة

- **المخزون**: يُخصم داخل معاملة عند تأكيد الطلب بشرط `stock >= qty` (لا بيع فوق المتاح)، ويُعاد عند الإلغاء. السلال (BUNDLE) تخصم مكوناتها.
- **الوزن الفعلي**: المنتجات الموزونة تُسعّر حسب الوزن المُدخل عند التجهيز؛ يُحفظ الإجمالي النهائي (`finalTotal`) ويظهر للعميل.
- **المواعيد**: قوالب أسبوعية بسعة وإغلاق حجز قبل الموعد بساعات؛ السعة تُراجع داخل معاملة الطلب.
- **الضريبة**: من الإعدادات (`vatEnabled`, `vatRate`, `pricesIncludeVat`) — معطّلة افتراضيًا حتى يكون النشاط مسجلًا ضريبيًا.
- **مناطق التوصيل ورسومها** تُدار من لوحة التحكم دون تعديل كود.
- **وعد التوصيل** لا يُعرض للعميل إلا إذا كتبه المدير في الإعدادات.
- **الاشتراكات**: `POST /api/internal/subscriptions/run` مع `Authorization: Bearer $CRON_SECRET` (مهمة يومية)، أو زر "تشغيل الآن" من لوحة التحكم.
- **الصور**: تُرفع إلى `STORAGE_LOCAL_DIR/uploads` وتُقدَّم عبر `/files/...` (فحص النوع بالبايتات السحرية، 5MB كحد أقصى).
